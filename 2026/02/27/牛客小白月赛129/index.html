# A. 小橘编译器

# B. 小橙的好序列

考虑 a 从 1 -> n 的每一个值都是他前一个值的 2 * k + 1 (1 是不变) 倍，递推过去即可 (注意边运算便取模)。

# C. 小橙的完美序列

由 ai = i ^ x 可知，x = ai * i , 在了解位运算后，我们采取贪心的做法，找到整个序列中数量最多的对于每一个数的 x , 然后用 n 减去即可。

# D&&E. 小橙的幸运数

考虑到实际上每次相加的数都是 a 中的某一个数。或者说，存在一个循环，使 x 沿循环移动，看是否能够到达 c。

# F. 小橙的异或和

由于考虑到对于 0 的修改没有意义，并且 0 对于结果并没有贡献，并且我们需要在操作过程中删去新出现的 0，所以我们需要维护的数据结构具有以下特点
1、可以有序排列数组下标
2、对于每一个 l , r 能够能很快的找到离他们最近的非 0 数组元素
3、删除元素的时间复杂度尽可能小
由此我们想到使用 set
由于 num ^ a ^ a == num , 所以我们可以在读入数据的时候放心的计算异或和，在后续修改的过程中先使用答案异或原来的数组元素，再异或新的数组元素即可
